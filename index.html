What this site is

A companion resource for criminal defense attorneys learning to use AI tools ethically. Every AI tool handles your data differently — some train on it, some sell it to advertisers, some delete it immediately. This site helps you figure out which tools are safe for which tasks.

Built for a 60-minute training session. Designed to be useful long after the presentation ends. Scan the QR code on the slides, bookmark this page, and come back whenever you're evaluating a new AI tool.

Who this is for: Missouri public defenders (MSPD), private criminal defense attorneys (MACDL), and any lawyer trying to use AI without violating ethics rules.

Missouri Your Jurisdiction

Missouri Informal Opinion 2024-11 requires you to assess the terms of service, security of inputs, and data sources of any AI tool you use with client work. This site is built around that requirement. Missouri-specific guidance is highlighted throughout.
